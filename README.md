# 🚀 راهنمای نصب و اجرا

برای اجرای صحیح پروژه، مراحل زیر را **به ترتیب** انجام دهید

---

## 01 — 📥 دریافت پروژه

ابتدا پروژه را دریافت کنید

اگر پروژه را از GitHub کلون می‌کنید، دستور زیر را در ترمینال اجرا کنید

```bash
git clone YOUR_REPOSITORY_URL
```

سپس وارد پوشه پروژه شوید

```bash
cd PROJECT_NAME
```

> اگر فایل پروژه را به صورت ZIP دریافت کرده‌اید، ابتدا آن را از حالت فشرده خارج کرده و پوشه پروژه را در **Visual Studio Code** باز کنید

---

## 02 — 🐍 بررسی نصب Python

برای اجرای پروژه به **Python** نیاز دارید

برای بررسی نصب بودن Python، دستور زیر را اجرا کنید

```bash
python --version
```

در بعضی سیستم‌ها ممکن است دستور زیر مورد نیاز باشد

```bash
python3 --version
```

اگر نسخه Python نمایش داده شد، می‌توانید ادامه دهید

---

## 03 — 🖥️ باز کردن پروژه در VS Code

**Visual Studio Code** را باز کنید

سپس از قسمت:

**File → Open Folder**

پوشه اصلی پروژه را انتخاب کنید

بعد از باز شدن پروژه، ترمینال VS Code را باز کنید

از منوی:

**Terminal → New Terminal**

---

## 04 — 🔐 ساخت محیط مجازی

برای جلوگیری از تداخل کتابخانه‌های پروژه با سایر پروژه‌های Python، پیشنهاد می‌شود یک محیط مجازی ایجاد کنید

```bash
python -m venv venv
```

### فعال‌سازی محیط مجازی در Windows

```bash
venv\Scripts\activate
```

اگر فعال‌سازی با موفقیت انجام شود، معمولاً عبارت `venv` در ابتدای خط ترمینال نمایش داده می‌شود

---

## 05 — 📦 نصب وابستگی‌های پروژه

اطمینان حاصل کنید که فایل زیر در پوشه اصلی پروژه وجود دارد

```text
requirements.txt
```

سپس دستور زیر را اجرا کنید

```bash
pip install -r requirements.txt
```

با اجرای این دستور، کتابخانه‌های موردنیاز پروژه نصب می‌شوند

---

## 06 — 🗄️ آماده‌سازی دیتابیس

حالا Migrationهای پروژه را اجرا کنید

```bash
python manage.py migrate
```

در صورت موفقیت، Django جداول موردنیاز دیتابیس را ایجاد می‌کند

---

## 07 — 👤 ساخت حساب مدیریت

برای ساخت حساب مدیریت Django، دستور زیر را اجرا کنید

```bash
python manage.py createsuperuser
```

سپس اطلاعات خواسته‌شده مانند:

* Username
* Email
* Password

را وارد کنید

> هنگام وارد کردن رمز عبور، ممکن است چیزی در ترمینال نمایش داده نشود
> این موضوع طبیعی است

---

## 08 — ▶️ اجرای سرور

حالا پروژه آماده اجرا است

دستور زیر را وارد کنید

```bash
python manage.py runserver
```

اگر اجرای سرور موفق باشد، پیامی مشابه زیر مشاهده خواهید کرد

```text
Starting development server at
http://127.0.0.1:8000/
```

---

## 09 — 🌐 مشاهده پروژه

کلید **Ctrl** را روی کیبورد نگه دارید

سپس روی آدرس زیر که در ترمینال نمایش داده شده کلیک کنید

```text
http://127.0.0.1:8000/
```

صفحه پروژه در مرورگر باز خواهد شد

### 🎉 پروژه با موفقیت اجرا شد

## 🔑 ورود به پنل مدیریت

اگر می‌خواهید وارد پنل مدیریت Django شوید، عبارت زیر را به آدرس پروژه اضافه کنید

```text
/admin/
```

بنابراین آدرس پنل مدیریت به شکل زیر خواهد بود

```text
http://127.0.0.1:8000/admin/
```

سپس با اطلاعاتی که هنگام ساخت `superuser` وارد کردید، وارد پنل مدیریت شوید

---

# 🛑 توقف سرور

برای متوقف کردن سرور، داخل ترمینال کلیدهای زیر را فشار دهید

```text
CTRL + C
```

برای اجرای مجدد پروژه، دوباره دستور زیر را اجرا کنید

```bash
python manage.py runserver
```

---

# ⚠️ خطاهای رایج

### ❌ `python is not recognized`

احتمالاً Python روی سیستم نصب نیست یا به PATH اضافه نشده است

ابتدا نصب بودن Python را بررسی کنید

```bash
python --version
```

---

### ❌ `No module named ...`

احتمالاً وابستگی‌های پروژه نصب نشده‌اند

دستور زیر را اجرا کنید

```bash
pip install -r requirements.txt
```

---

### ❌ `can't open file 'manage.py'`

احتمالاً ترمینال در پوشه اصلی پروژه قرار ندارد

مطمئن شوید فایل زیر در مسیر فعلی وجود دارد

```text
manage.py
```

سپس دوباره دستور اجرای پروژه را امتحان کنید

```bash
python manage.py runserver
```
