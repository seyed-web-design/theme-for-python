## 🚀 اجرای پروژه

برای اجرای صحیح پروژه، مراحل زیر را به ترتیب انجام دهید

### 01 — 📂 باز کردن پروژه

ابتدا **Visual Studio Code** را باز کنید و پوشه پروژه را داخل آن باز کنید

سپس از قسمت **Terminal**، ترمینال پروژه را باز کنید

---

### 02 — 📦 نصب وابستگی‌ها

دستور زیر را اجرا کنید

```bash
pip install -r requirements.txt
```

---

### 03 — 🗄️ آماده‌سازی دیتابیس

Migrationهای پروژه را اجرا کنید

```bash
python manage.py migrate
```

---

### 04 — 👤 ساخت حساب مدیریت

برای ساخت حساب کاربری مدیریت، دستور زیر را اجرا کنید

```bash
python manage.py createsuperuser
```

سپس اطلاعات موردنیاز را وارد کنید

---

### 05 — ▶️ اجرای پروژه

سرور Django را با دستور زیر اجرا کنید

```bash
python manage.py runserver
```

پس از اجرای موفق، آدرسی مشابه زیر در ترمینال نمایش داده می‌شود

```text
http://127.0.0.1:8000/
```

حالا کلید **Ctrl** را نگه دارید و روی آدرس کلیک کنید
