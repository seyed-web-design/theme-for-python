🚀 آموزش اجرای قالب

برای اجرای این قالب مراحل زیر را به ترتیب انجام دهید

🖥️ مرحله اول — باز کردن Visual Studio Code

ابتدا Visual Studio Code را باز کرده و پوشه قالب را در آن اجرا کنید

سپس از قسمت Run یا ترمینال VS Code استفاده کنید

⚙️ مرحله دوم — نصب وابستگی‌ها

دستور زیر را در ترمینال وارد کنید

pip install -r requirements.txt
🗄️ مرحله سوم — اجرای Migration

سپس دستور زیر را اجرا کنید

python manage.py migrate
👤 مرحله چهارم — ساخت کاربر مدیریت

برای ساخت کاربر ادمین دستور زیر را وارد کنید

python manage.py createsuperuser

سپس اطلاعات خواسته‌شده را وارد کنید

▶️ مرحله پنجم — اجرای قالب

در نهایت دستور زیر را اجرا کنید

python manage.py runserver

پس از اجرای موفق، آدرسی مشابه زیر در ترمینال نمایش داده می‌شود

http://127.0.0.1:8000/

کلید Ctrl را روی کیبورد نگه دارید و روی آدرس نمایش‌داده‌شده کلیک کنید تا قالب در مرورگر باز شود

⚠️ هشدار

❌ بنده هیچ ضمانتی در قبال این قالب بر عهده نمی‌گیرم
❌ هرگونه اتفاق، خرابی یا مشکل ناشی از استفاده از این قالب بر عهده شخص استفاده‌کننده می‌باشد
❌ لطفاً قبل از استفاده، قالب را در محیط مناسب تست کنید
